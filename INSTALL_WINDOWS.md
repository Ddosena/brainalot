# Установка Brainalot на Windows

## Установка через Setup

Нужны Windows 10/11 x64 и Chrome 116+. Python отдельно не требуется.

1. Скачайте `BrainalotApp-win-Setup.exe` из
   [релиза](https://github.com/Ddosena/brainalot/releases/latest) и запустите.
2. На странице приветствия выполните инструкцию подключения расширения.
   До публикации в Chrome Web Store используется «Загрузить распакованное
   расширение» с папкой, которую показывает программа.
3. Откройте боковую панель Brainalot: Native Messaging автоматически передаст
   ей порт и токен. При отсутствии приложения панель показывает загрузку и
   «Подключиться снова».

Библиотека — в `Documents\Brainalot`, состояние — в `%LOCALAPPDATA%\Brainalot`.
Удаление программы сохраняет записи. Обновления программа получает из релизов
`Ddosena/brainalot`; исходники доступны там же. Цифровой подписи пока нет.

## Установка из исходников (для разработки)

1. Установите Python 3.12 или новее с сайта Python. При установке разрешите
   добавление Python Launcher (`py`).
2. Распакуйте архив Brainalot в постоянную папку, например `D:\Apps\Brainalot`.
3. Дважды нажмите `Install-MegaMozg.cmd`. Установщик создаст `.venv`, установит
   зависимости, создаст пустую локальную библиотеку и покажет токен.
4. Для первого запуска нажмите `Start-Service.cmd`. Он запустит сервис в фоне
   без постоянно открытого окна терминала.
5. В Chrome откройте `chrome://extensions`, включите «Режим разработчика»,
   нажмите «Загрузить распакованное расширение» и выберите `D:\Apps\Brainalot\extension`.
6. Нажмите значок Brainalot, откройте боковую панель, зайдите в «Настройки», вставьте
   токен и нажмите «Подключить».
7. Чтобы сервис запускался скрыто при входе в Windows, один раз выполните
   `Enable-Autostart.cmd`.
8. Для Obsidian выберите «Открыть папку как хранилище» и укажите `data\vault`.

Повторно получить токен можно командой:

```powershell
.venv\Scripts\python.exe -m megamozg token
```

## Google Календарь

Для каждого нужного календаря повторите следующие шаги:

1. Откройте Google Календарь на компьютере и нажмите значок настроек.
2. Слева в разделе «Настройки моих календарей» выберите календарь.
3. Откройте «Интеграция календаря» и скопируйте «Секретный адрес в формате
   iCal». Не используйте обычную публичную ссылку.
4. В боковой панели Brainalot откройте «Настройки» → «Google Календарь».
5. При желании укажите понятное название, вставьте секретную ссылку и нажмите
   «Добавить календарь».

Все подключения отображаются списком, а их события объединяются в общем
расписании. Кнопка «Удалить» отключает только выбранный календарь;
«Отключить все» удаляет все подключения. По iCal календари доступны для чтения;
изменение событий требует отдельного подключения Google API, описанного ниже.

Секретная iCal-ссылка даёт доступ к расписанию как пароль. Не публикуйте и не
отправляйте её другим людям. Ссылки хранятся только локально в `data/state` и
не показываются обратно в панели или API.

Панель автоматически проверяет события примерно каждые 10 секунд. Для iCal
загрузка у Google после успешного запроса выполняется не чаще раза в минуту;
авторизованный Google API кэшируется 10 секунд. Если Google временно отвечает
ошибкой 429, Brainalot покажет последнюю сохранённую копию, а позже повторит загрузку
с увеличенной задержкой.
При такой временной ошибке длинный текст не занимает место в панели: рядом с
заголовком расписания появляется только маленький значок `⚠` с пояснением при
наведении.

## Оформление и светлый/тёмный режим

Нажмите палитру в шапке панели. В «Оформлении» можно выбрать «Ленту»,
«Картотеку», «Пульт» или розовый «Гламур» с сердечками. Отдельно выберите режим:

- «Как в системе» — тема следует настройке Windows;
- «Светлая» — всегда используется светлое оформление;
- «Тёмная» — всегда используется тёмное оформление.

Выбор сохраняется в локальном профиле Chrome и не требует перезапуска сервиса.

«Язык» переключает интерфейс между русским и английским. Панель и открытые
окна Brainalot сразу перезагружаются на выбранном языке, черновик окна «Записать»
сохраняется. Пока язык не выбран, Brainalot следует языку Chrome. Разбор текста
поддерживает русскую речь и базовые английские фразы; непонятный текст попадает
во «Входящие». Проверяйте результат в блоке «Понял так» перед сохранением.

## Таймер поверх Chrome

Кнопка ▶ рядом с помидоркой запускает отсчёт. Локальный сервис рисует тонкую
красную полосу над активным окном Chrome, поэтому она остаётся на месте при
смене вкладок и сайтов. Нажмите на помидорку и снимите галочку «Полоса поверх
Chrome», чтобы скрыть её, не останавливая таймер. При обновлении Brainalot перезапустите
локальный сервис и обновите расширение на `chrome://extensions`; открытые
страницы для нативной полосы обновлять не нужно.

## Быстрая запись

Нижняя кнопка «Записать» открывает компактное отдельное окно Chrome по центру
текущего окна браузера. Курсор сразу находится в поле текста. Пишите или
диктуйте как есть: Brainalot сам разбирает тип записи, дату, время, повтор, проект или
человека и важность. Ctrl+Enter сохраняет запись в локальную очередь и закрывает
окно. Если сервис недоступен, очередь дождётся подключения. Escape или закрытие
окна оставляет черновик для следующего открытия. Повторное нажатие «Записать»
возвращает фокус уже открытому окну.

Лупа в шапке открывает поиск в библиотеке, включая названия связанных проектов
и людей. Библиотека занимает всю рабочую область панели. Кнопка в её
заголовке «Открыть в окне» разворачивает библиотеку в отдельное большое окно
по центру браузера; «Вернуть в панель» возвращает её обратно. Раздел, проект,
поиск и раскрытые записи сохраняются. Закройте библиотеку в панели,
чтобы вернуться к «Сегодня» и «Вспомнить». Слева в библиотеке — разделы,
справа — записи. Откройте «Проекты» и выберите проект: появится его досье с
мыслями, делами, материалами и вложениями. Разделы собираются из записей,
связанных с проектом; пустые физические папки и копии заметок не создаются.
Карточка «Вспомнить» выглядит как веер листов; при перелистывании передняя
карточка поворачивается в сторону жеста. Раскрытая карточка выпрямляется,
а при включённом уменьшении движения в ОС сменяется без пространственной анимации.
Карточки можно листать перетягиванием мышью, свайпом или стрелками
клавиатуры на сфокусированном блоке. Нажатие на запись раскрывает подробности.
Автоматическая смена происходит примерно раз в минуту. Ручной выбор сохраняется
60 секунд и пока раскрыты подробности, затем снова
работает автоматическая смена. Входящие, дела/покупки на сегодня, неактивные,
отложенные и скрытые записи сюда не попадают. Сами проекты тоже исключены:
показываются их подходящие записи, включая мысли и картинки. Будущие дела участвуют.
Зелёная точка рядом с Brainalot означает подключение; время обновления списков
находится в общих настройках. Календарь и ранее сохранённое подключение при
смене оформления сохраняются.

Под выбранным днём находятся вкладки «Без срока», «На неделе», «На месяц»
и «Мысли». Общего видимого заголовка у этого блока нет. «Мысли» показывает
активные мысли и идеи; выбор вкладки сохраняется после переоткрытия панели.

### Разбор текста

Под полем текста блок «Понял так» показывает, что получится: тип записи, день и
время, куда запись уйдёт, проект или человека, важность, теги и название.
Разбор работает по правилам на этом компьютере, без модели и облака.

- Фраза с точным временем или повтором («поставь на сегодня вынести мусор с 15
  до 16», «по будням в 9 стендап») становится событием в первом подключённом
  Google Календаре и появляется в «Сегодня». Для этого нужен Google API из
  раздела «Изменение событий Google Календаря»; без него запись станет делом на
  этот день, а время попадёт в название.
- «Сохранить делом» оставляет время в названии дела вместо события,
  «Вернуть в календарь» отменяет это.
- «Тип записи», «Когда», «Проект или человек» и «Важность» по умолчанию стоят на
  «Авто · …» и показывают решение разбора. Значение, выбранное вручную, становится
  исправлением: выбранный день переносит сказанное время на этот день, «Без
  срока» и «На неделе»/«На месяц» убирают время, выбранная «Мысль» или «Идея» —
  тоже.
- Запись с файлами остаётся в Brainalot: событие не создаётся, время попадает в
  название дела.
- Непонятный текст по-прежнему попадает во «Входящие». Текст длиннее 2000
  символов и запись только из файлов сохраняются как есть, без разбора.
- Без сервиса разбор не показывается, но запись ждёт в очереди и разбирается при
  отправке; «завтра» считается от момента сохранения, а не отправки.

## Голосовой ввод

Кнопка с микрофоном в поле текста окна «Записать» записывает речь. Распознаёт её
программа faster-whisper на этом компьютере; звук никуда не отправляется.

1. В Setup движок уже включён. Только при установке из исходников один раз
   запустите `Install-Voice.cmd` и перезапустите локальный сервис.
2. Нажмите микрофон. При первом нажатии Brainalot скачает модель распознавания (около
   500 МБ) в `%LOCALAPPDATA%\Brainalot\state\models` (для исходников —
   `data\state\models`); это займёт от минуты до нескольких минут,
   значок в это время мигает. Когда модель готова, запись начинается сама, если
   окно «Записать» открыто; иначе нажмите микрофон ещё раз.
3. Разрешите Chrome доступ к микрофону для Brainalot. Боковая панель не умеет
   показывать этот запрос, поэтому голос доступен в окне «Записать».
4. Говорите. Паузы, чтобы подумать, запись не прерывают: закончите её повторным
   нажатием микрофона. Сама она остановится только после минуты тишины или
   через 5 минут. Распознанный текст встаёт в поле, а «Понял так» показывает разбор.
   Escape останавливает запись, Ctrl+Enter дожидается текста и сохраняет запись.

По умолчанию используется модель `small`. На быстром компьютере точнее
`large-v3-turbo`: выполните `setx MMM_WHISPER_MODEL large-v3-turbo` (для
видеокарты NVIDIA также `setx MMM_WHISPER_DEVICE cuda`) и перезапустите сервис.
Названия активных проектов и людей подсказываются распознаванию, поэтому имена
из библиотеки узнаются лучше.

## Таймер фокуса

Нажмите помидорку в шапке панели: откроются настройки. Выберите 20, 25, 30
или 50 минут либо задайте своё время от 1 до 180 минут. Запустите таймер;
тонкое кольцо вокруг помидорки заполняется по мере прохождения интервала. Можно
поставить его на паузу, продолжить или сбросить. Закрытие боковой панели не
останавливает отсчёт. После завершения перерыв не запускается автоматически:
следующий интервал выбираете вы. Таймер не изменяет задачи и записи библиотеки.
Кнопка рядом со временем ставит отсчёт на паузу или продолжает его. Настройки
закрываются по Escape или нажатию снаружи; таймер доступен и в библиотеке.

## Записи, редактирование и перенос

- Нажмите на строку записи, чтобы раскрыть её подробности и настройки.
- «Изменить» находится внутри настроек записи, а не отдельной большой кнопкой
  возле названия.
- Отдельной ручки из шести точек нет: перетаскивайте запись за строку с
  названием.
- Бросать запись можно на всю область «Сегодня», «Без срока», «На неделе»,
  «На месяц» или «Входящие», а не только на заголовок блока.
- В списке сегодняшних дел отдельный треугольник раскрытия не показывается:
  подробности открываются обычным нажатием на строку.

## Изменение событий Google Календаря

Секретная iCal-ссылка позволяет только читать расписание. Для переноса и
удаления событий подключите Google Calendar API:

1. В Google Cloud создайте или выберите проект и включите Google Calendar API.
2. В Google Auth platform настройте экран согласия. Для тестового внешнего
   приложения добавьте свой Google-аккаунт в Test users.
3. Создайте OAuth Client ID типа **Desktop app** и скачайте JSON-файл.
4. В Brainalot откройте «Настройки» → «Google Календарь» → «Изменение событий».
5. Выберите JSON и нажмите «Подключить Google API».
6. В открывшейся вкладке Google подтвердите доступ и вернитесь в панель Brainalot.

После подключения нажмите событие в расписании. Кнопка «Перенести» меняет его
дату в Google, а «Удалить этот день» удаляет выбранное событие. Для повторяющейся
серии изменяется только выбранный экземпляр. Участникам не отправляются письма
об этих изменениях (`sendUpdates=none`). OAuth JSON и токены хранятся только в
`data/state`, не публикуются и не входят в backup.

Перенос и удаление сразу отображаются в панели, пока запрос выполняется в
фоне. При ошибке событие возвращается на прежнее место и появляется сообщение
с причиной. Удаление обычной записи работает так же. Успешное уведомление
исчезает примерно через две секунды.

## Перенос на другой свой компьютер

1. На старом компьютере полностью закройте Brainalot или остановите локальный сервис.
2. Скопируйте всю папку `data` в безопасное место. В ней находятся vault,
   история и локальные настройки календаря.
3. На новом компьютере распакуйте чистый релиз Brainalot и выполните установку.
4. Остановите сервис на новом компьютере и замените созданную папку `data`
   сохранённой копией.
5. Снова запустите сервис. Получите токен командой выше и вставьте его в новый
   профиль Chrome. Старый токен можно использовать только если перенесён весь
   `data/state`, но повторное получение надёжнее.
6. Загрузите папку `extension` в Chrome и откройте `data/vault` в Obsidian.

Для передачи проекта другим людям отправляйте только релизный ZIP. Свою папку
`data` не прикладывайте: в ней находятся личные заметки и календарные секреты.

## Картинки и документы

В окне «Записать» или в редакторе существующей записи нажмите «Добавить файлы»
и выберите файлы с компьютера. Скопированную картинку можно вставить Ctrl+V
в поле текста. До сохранения вложения можно удалить из списка. Можно сохранить
новую запись с файлами и без текста.

Максимум — 10 файлов, до 10 МиБ каждый и 30 МиБ суммарно. Изображения
PNG/JPEG/GIF/WebP видны прямо в карточках панели без предварительного раскрытия.
В библиотеке изображение показывается внутри раскрытой строки. Документы можно скачать из
раскрытой записи. SVG и HTML сохраняются как файлы без встраивания в панель.
Вложения находятся в `data/vault/8 Вложения` и переносятся вместе с `data`.
Markdown-ссылки в заметке позволяют открыть их в Obsidian.

Пока сервис недоступен, новая запись с файлами остаётся в очереди этого
профиля Chrome. Для переноса библиотеки сначала дождитесь отправки очереди.
Удаление вложения из записи не стирает исходный файл: он остаётся для отмены
операций и восстановления истории. Черновики/неотправленные файлы Chrome
не входят в резервную копию сервиса.

## Обновление

В версии 0.1.38 окно «Записать» разбирает написанное и надиктованное: показывает
«Понял так», создаёт события Google Календаря по фразам со временем и принимает
голос после `Install-Voice.cmd`. Интерфейс можно переключить на английский в
«Настройки → Оформление → Язык». Полоса таймера заполняется слева направо по
верхнему краю страницы, а цвет её неона выбирается в меню таймера. При
обновлении расширения таймер возвращается к 25:00 на паузе: прошедшее время не
переносится, отсчёт и полоса ждут ручного продолжения. Для обновления замените
файлы программы, перезапустите локальный сервис (разбор, голос и цвет полосы
есть только в новом сервисе), затем нажмите «Обновить» у Brainalot на
`chrome://extensions`. Если окно «Записать» просит перезапустить сервис,
работает прежний процесс: записи ждут его в очереди и уйдут после перезапуска.
Незаконченный черновик сохраняется, его поля со значениями по умолчанию
переходят на «Авто».
Сервис теперь работает под надзором: если его процесс завершился (например,
вместе с закрытой программой, из которой его запустили), он поднимается снова
за несколько секунд, а панель подхватывает его сама. При включённом автозапуске
`Start-Service.cmd` запускает сервис через задачу автозапуска. Чтобы подхватить
новый код, достаточно завершить процесс `python` сервиса Brainalot. Голосовой ввод
открывает уже скачанную модель без обращения к интернету, поэтому работает и
без VPN. Надзор начинает работать после первого перезапуска сервиса новыми
файлами: завершите прежний процесс `python` сервиса и запустите `Start-Service.cmd`.

В версии 0.1.37 полоса Pomodoro стала отдельным окном поверх Chrome, а в меню
таймера появился переключатель её видимости. Для этого обновления замените
файлы программы, перезапустите локальный сервис, затем нажмите «Обновить» у Brainalot
на `chrome://extensions` и снова откройте боковую панель. Минус рядом с
отмеченным кружочком снимает важность дела или события одним нажатием.
Для перезапуска сначала завершите прежний процесс локального сервиса Brainalot, затем
запустите `Start-Service.cmd`. Повторный запуск одного `Start-Service.cmd`, пока
старый сервис отвечает на `/api/health`, оставляет прежний процесс и код в
памяти. Если панель пишет «старой версией полосы», сервис ещё не заменён.

В версии 0.1.34 «Вспомнить» показывает соседние карточки: нажмите на боковую
карточку или край передней, чтобы перелистать. Один щелчок по делу раскрывает
подробности, двойной меняет важность без раскрытия. Важность выделена более
заметным контуром. Точки важности у дел и событий стоят в одном правом столбце;
нажатие превращает точку в кружок с точкой. Маркеры можно скрыть в
«Настройки → Важные дела».
Календарные события на весь день стоят первыми и выглядят компактнее; подсветка
приближающихся событий стала спокойнее. Сервис проверяет iCal раз в минуту
вместо 15 минут. После обновления расширения переоткройте панель, а для нового
интервала календаря перезапустите локальный сервис.

Версия 0.1.30 открывает библиотеку на всю панель и позволяет вынести её
в большое окно. Добавлена вкладка «Мысли» и крупные изображения в карточках.
Обновите расширение в Chrome и перезапустите локальный сервис: сами проекты
теперь исключены из карусели, а связанные мысли и материалы остаются в ней.

При переходе с версии до 0.1.28 обновите также локальный сервис: изменён состав
карусели «Вспомнить». После замены файлов перезапустите сервис и обновите Brainalot
в Chrome. Старый сервис сохраняет прежние правила отбора карточек.
Библиотека «Проводник» доступна через «Все записи» и лупу в шапке, открывается
на всю рабочую область; «Все записи» позволяет искать также дела, входящие и архив.

Распакуйте новую версию поверх отдельной новой папки, перенесите в неё `data`,
повторно запустите установщик и нажмите «Обновить» у расширения на
`chrome://extensions`. Перед обновлением сохраните копию `data`.

## Проверка

- После запуска `Start-Service.cmd` страница `http://127.0.0.1:8765/api/health`
  возвращает состояние `ok`.
- После запуска `Start-Service.cmd` окно терминала закрывается, а сервис остаётся
  доступен. Диагностические файлы находятся в `data\state\logs`.
- Если процесс сервиса завершить, через несколько секунд `/api/health` снова
  отвечает `ok`; запуски и завершения записаны в `data\state\logs\supervisor.log`.
- В панели написано «Сервис подключён».
- Новая мысль появляется в `data\vault`.
- Секретные iCal-ссылки не находятся в Markdown-файлах vault.

## Кнопки «Запустить сервис» и «Перезапустить сервис»

В настройках панели (шестерёнка) есть кнопки «Обновить», «Запустить сервис» и «Перезапустить сервис». Они не требуют терминала или агента: расширение просит маленькую программу `megamozg.native_host` поднять сервис. `Install-MegaMozg.cmd` подключает её сам; если вы загрузили расширение позже или из другой папки, один раз запустите `Register-NativeHost.cmd`, затем обновите расширение в `chrome://extensions`. Программа пишет только в раздел реестра текущего пользователя `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.brainalot.host`, не открывает порты и принимает лишь три команды: `status`, `start`, `restart`. Если кнопка пишет, что не подключена, запустите `Start-Service.cmd`.
