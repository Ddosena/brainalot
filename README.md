# Brainalot

Локальный менеджер мыслей, дел и расписания. Brainalot хранит данные в обычных
Markdown-файлах для Obsidian, показывает день в боковой панели Chrome и даёт
Codex или Claude единый CLI для записи надиктованных мыслей.

## Что умеет

- быстрый ввод через нижнюю кнопку «Записать» и отдельное центральное окно Chrome;
- разбор написанного и надиктованного: тип, дата, время, повтор, проект, важность; блок «Понял так» показывает результат до сохранения, а «Авто» в полях можно исправить вручную;
- фраза со временем («завтра в 10 созвон») становится событием Google Календаря, без доступа на запись — делом со временем в названии;
- голосовой ввод в окне «Записать»: речь распознаётся на этом компьютере; движок включён в Setup, модель загружается при первом включении;
- русский и английский интерфейс: переключение кнопкой с глобусом в шапке;
- вставка картинок через Ctrl+V и прикрепление документов/изображений с компьютера;
- изображения прямо в карточках, скачивание вложений, локальные файлы и ссылки в Obsidian;
- дела на выбранный день, вкладки «Без срока», «На неделе», «На месяц» и «Мысли»;
- объединение нескольких Google Календарей по секретным iCal-ссылкам;
- перенос и удаление выбранных экземпляров событий через локальный Google OAuth; чекбокс удаляет только этот день повторяющейся серии;
- автоматическое обновление расписания при открытой панели без кнопки обновления;
- выделение важных дел и событий контуром или комиксным «Огнём» (одно на день), который разгорается от места щелчка: двойной щелчок или кружок, который можно скрыть в настройках;
- звук розжига «Огня» на выбор в настройках: «Костёр», «Бумага», «Факел» или без звука; он длится столько же, сколько розжиг;
- оформления «Лента», «Картотека», «Пульт», розовый «Гламур» с сердечками: выбор кнопкой с палитрой в шапке;
- независимый светлый, тёмный или системный режим в том же меню, сохранение выбора и черновика;
- библиотека «Проводник» на всю панель с разделами, поиском и досье проектов;
- кнопка разворачивания библиотеки в большое окно и возврата с сохранением места;
- в досье — мысли и идеи, дела, материалы и записи с вложениями;
- карточка «Вспомнить» в виде стопки: видны соседние записи, переход по боковой карточке, свайп и автоматическая смена;
- компактный таймер в шапке: помидорка с кольцом прогресса, пресеты и своё время без автоперерывов; локальный сервис показывает заполняющуюся полосу у верхнего края страницы Chrome независимо от сайтов, вкладок и фокуса другого приложения, пока место полосы не перекрыто; переключатель в меню таймера скрывает её без остановки отсчёта; обновление расширения сбрасывает таймер к 25:00 на паузе;
- маленький минус рядом с отметкой важности снимает обводку дела или события одним нажатием, даже когда единственная огненная отметка занята другим элементом;
- библиотека Markdown, которую можно открыть как vault Obsidian;
- локальный журнал изменений, защита от повторной доставки и отмена операций;
- общий интерфейс для агента, ручного окна и расширения Chrome.

Заметки хранятся локально: после Setup — в `Documents\Brainalot`, при запуске
из исходников — в `data/`. Подключённый Google Календарь синхронизируется с Google.
API-ключ модели для обычной работы не нужен. Сетевые обращения описаны
в [политике конфиденциальности](PRIVACY.md).

## Быстрый запуск на Windows

Нужны Windows 10/11 x64 и Google Chrome 116 или новее. Setup включает Python.
Obsidian необязателен, но удобен для чтения библиотеки.

1. Откройте [релизы Brainalot](https://github.com/Ddosena/brainalot/releases/latest),
   скачайте `BrainalotApp-win-Setup.exe` и запустите его.
2. Следуйте открывшейся странице приветствия. Пока расширение не опубликовано
   в Chrome Web Store, она покажет папку для «Загрузить распакованное расширение»
   на `chrome://extensions`.
3. Откройте боковую панель. Программа запускается и подключается автоматически,
   токен копировать не нужно. Если программа ещё не установлена, панель покажет
   ссылку на загрузку и кнопку повторного подключения.
4. Для Obsidian откройте папку `Documents\Brainalot` как хранилище.

Это ранний выпуск: установщик пока не имеет цифровой подписи. Исходная установка
с Python остаётся доступна для разработки в [INSTALL_WINDOWS.md](INSTALL_WINDOWS.md).

Подробности, перенос между компьютерами и подключение календаря описаны в
[INSTALL_WINDOWS.md](INSTALL_WINDOWS.md).

## Работа через агента

Откройте эту папку как проект Codex или Claude и попросите сохранить запись в
Brainalot. Агент использует локальную команду:

```powershell
.venv\Scripts\python.exe -m megamozg capture --text "Идея для проекта" --kind idea --source codex --external-id UNIQUE_ID
```

Чтобы разобрать фразу так же, как окно «Записать», используйте
`mmm parse --text "..."` (только показать) или
`mmm dictate --text "..." --external-id UNIQUE_ID` (сохранить).

Готовые правила работы находятся в [AGENTS.md](AGENTS.md). Команда `mmm`
доступна после установки; историческое имя `megamozg` сохранено для совместимости.

## Разработка

```powershell
.venv\Scripts\python.exe -m pytest
node --test extension/tests/*.test.mjs
```

## Приватность

Не публикуйте `data/`, `backups/`, `.env` и секретные iCal-ссылки. Публичная
сборка создаётся по белому списку и не включает пользовательский vault.
